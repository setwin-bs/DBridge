# Security Policy

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Report privately via a security advisory on this repository (Security → Report a vulnerability). If that channel is unavailable, contact @jpalma-setwin directly.

## What to include

- Reproduction: minimal steps, request or script that shows the issue.
- Impact: what an attacker gains, and the conditions required.
- Versions: affected version or commit and environment.

## Response expectations

- Acknowledgement within `<e.g. 48h>`.
- Triage and severity assessment within `<e.g. 7 days>`.
- Progress updates at least every `<e.g. 7 days>` until resolution.

## Disclosure policy

- We confirm the fix and coordinate a disclosure date with the reporter.
- Please allow `<e.g. 90 days>` before public disclosure.
- Credit is given in release notes if the reporter agrees; anonymous reports are welcome.
